# Цифровое Искусство — школа дизайна для школьников 5–8 классов

Одностраничный сайт (лендинг) для курса по цифровому искусству, включающий:

- Продающий блок с преимуществами
- 5 модулей обучения
- Портфолио работ учеников (5 карточек с изображениями)
- Форма записи на курс (сохраняет заявки в localStorage)
- Админ-панель для управления заявками и видео (защищена паролем)
- Отдельная страница с видеоуроками (доступ по email)
- Смена тёмной/светлой темы (запоминается в браузере)
- Полная адаптивность под все устройства

## 🚀 Как запустить локально

1. **Убедитесь, что у вас установлен Python 3** (на Mac/Linux обычно есть, на Windows установите с python.org).
2. Откройте терминал в папке проекта и выполните:
   ```bash
   python3 -m http.server 8000
Откройте браузер и перейдите по адресу:
http://localhost:8000

Если хотите использовать Live Server в VS Code – установите расширение, откройте папку проекта и нажмите «Go Live».

🔐 Админ-панель
Админ-панель доступна по адресу:
http://localhost:8000/admin.html

Первый вход
При первом открытии вам будет предложено установить пароль (минимум 4 символа).

Введите пароль и нажмите «Установить».

После этого пароль сохранится в браузере, и в следующий раз нужно будет его вводить для входа.

Возможности админ-панели
Заявки: просмотр, отметка «Обработано», ответ (текст сохраняется), удаление.

Видео: добавление новых видеоуроков (название + ссылка YouTube/Vimeo) и удаление.

Смена темы: кнопка в верхнем правом углу переключает светлую/тёмную тему.

Если забыли пароль
Откройте консоль браузера (F12) и выполните:

javascript
localStorage.removeItem('adminPasswordHash');
location.reload();
После этого можно будет установить новый пароль.

📹 Видеоуроки
На главной странице есть кнопка «Получить 3 бесплатных урока».

После ввода email в модальном окне доступ сохраняется, и пользователь перенаправляется на страницу video.html.

Видео добавляются через админ-панель и отображаются на странице видео.

Если доступ не получен, страница видео показывает сообщение о необходимости получить доступ на главной.

📱 Адаптивность
Сайт корректно отображается на всех устройствах:

Десктопы (≥ 1200px)

Планшеты (768–992px)

Мобильные телефоны (≤ 480px)

Карточки работ подстраиваются под размер экрана, шрифты используют относительные единицы, навигация превращается в гамбургер-меню.

HTML5

CSS3 (Flexbox, Grid, CSS-переменные, медиазапросы)

localStorage для хранения данных (заявки, видео, пароль, тема, доступ к видео)

🧪 Особенности
Все данные хранятся в localStorage браузера – это демо-версия без сервера. Для продакшена потребуется база данных и бэкенд.

Заявки не отправляются автоматически по email – администратор видит их в админке и связывается по телефону.

Пароль админки хранится в закодированном виде (btoa), что подходит для демонстрации, но не для реальной безопасности.
